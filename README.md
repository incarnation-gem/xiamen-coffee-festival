# 厦门美好咖啡节 · 38 家品牌图鉴

「美好的咖啡 NICENESS COFFEE 2026 · 城市游牧计划 · 厦门站」（S12）参展品牌的调研图鉴静态站。

**活动**：2026-11-19 ～ 11-22，每天 11:00–20:00，厦门万象城二期·微笑广场，免票入场，38 家品牌（约六成首次进厦门）。

## 站点用法

- 打开 `index.html` 即用（零构建、零依赖，file:// 可直开；线上走 GitHub Pages）。
- 按摊位区（A/B）、类型（冠军 / 意式 / 手冲 / 特调 / 非咖啡）、首进筛选。
- 每家可标记 **想喝 / 已喝 / 跳过**，标记存本机 localStorage（换设备不同步），顶部统计实时更新。
- 每张卡片附「小红书口碑 ↗」，跳转小红书站内搜索该品牌的最新口碑。

## 数据口径

- **主推产品**：主办方「NICENESS美好事物所」官方《参展品牌必喝list》（含 A/B 区摊位号）。
- **口碑 / 招牌 / 价格**：小红书公开笔记聚合——38 组品牌搜索（每组前 25+ 条标题信号）+ 76 篇笔记正文与评论区精读，采集于 2026-11-18（开幕前一天）。非亲测，价格为门店或往站咖啡节档，现场以摊位为准。
- **冠军头衔**：主办方官宣帖。WBC/CBC 为世界/中国咖啡师大赛（意式方向）；冲煮、杯测、拼豆、烈酒、MOB 为各专项赛。
- 负面口碑（如北平冰匠 set 避雷帖、GTS 摊位规则争议）如实收录并标注，供自行判断。
